# Fontaine – Vachier-Lagrave : un second exemple

**Partie** : Robert Fontaine – Maxime Vachier-Lagrave, championnat de France, Aix-les-Bains, ronde 10, 23 août 2007. **Résultat** : 0-1 en 39 coups (78 demi-coups). Elo : 2567 et 2595.

Ouvrez `Fontaine_MVL_territoire.html` (double-clic). Les deux tests de validation de l'application ont été lancés sur cette partie : 0 désaccord.

## Quelques repères relevés par l'application (sans les pions)
- **Flux maximal** : Blancs 57 au coup 18…hxg3, Noirs 61 au coup 22.Cxf5.
- **Équilibre** : dans 14 des 78 demi-coups, les deux flux sont à moins de 2 points l'un de l'autre.
- **Les plus gros gains** : 13.Dxd4 pour les Blancs (+29 de solde de flèches), 17…Dc5 pour les Noirs (+23).
- **Sous-promotion** : 35…f1=C+ (un Cavalier, avec échec), solde de flèches +21.
- **Phase d'attaque noire** : aux coups 26…Th8, 29…b5 et 30…e3, le Roi blanc n'a aucune fuite libre.

Ce sont des repères pour **regarder** la partie, pas un jugement sur elle.
